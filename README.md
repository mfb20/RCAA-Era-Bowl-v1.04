# RCAA ERA BALL v1.04

RCAA ERA BALL v1.04 continues from v1.03 and expands both the historical season simulator and the single-player draft experience.

## v1.04
- Updated S5, S10, S15, and S17 offensive ratings/award traits.
- Added Perko to S13 CJSU and S17 CJSU.
- Complete historical teams now have a calculated Team OVR and strength tier: Bad, OK, Good, or Legendary.
- Standard/Bench/Nightmare seasons use real historic-team opponents: 2 Bad, 2 OK, 2 Good in the regular season; Good in the semifinal; Legendary in the Bowl.
- Regular-season and playoff player statistics are shown separately.
- OPOY favors a WR unless no WR had a remarkable regular season and the QB did.
- New Fantasy Draft mode: choose draft slot 1–4, snake draft 7 players against 3 CPUs from every historical player instance, then simulate a 4-team double round robin and 3-team playoff.
- Fantasy standings use record, then point differential, then points scored.
- Seven additional high-quality profile images were added for the requested player/season ranges.

GitHub Actions validates and deploys the game to GitHub Pages.
